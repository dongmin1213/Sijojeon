# 시조전 — 게임 컨셉

> 버전: 1.0 | 최종 업데이트: 2026-04-09

---

## 요약

조선시대 배경의 모바일 덱빌딩 로그라이크 게임.
Slay the Spire 스타일의 턴제 카드 전투 + 런마다 새로운 덱 구성.
1인 개발 (Claude Code 바이브코딩 + Gemini 카드 일러스트).

---

## 확정 결정 사항

| 항목 | 결정 |
|------|------|
| 장르 | 덱빌딩 로그라이크 (Slay the Spire 스타일) |
| 배경 | 조선시대 — 한국 역사/설화 기반 |
| 엔진 | Godot 4 (GDScript) |
| 플랫폼 | 모바일 Android (구글 플레이 + 원스토어) |
| 핵심 방향 | 순수 덱빌딩 — 런마다 리셋, 가챠 없음 |
| 개발 방식 | Claude Code 바이브코딩 (AI 주도 개발) |
| 아트 | Gemini로 카드 일러스트 생성 (정적 이미지) |
| 핵심 메카닉 | 시조 리듬 시스템 (A안 확정) |

---

## 차별화 포인트

**시조 리듬 시스템** — 리듬+덱빌딩 조합, 상업적 규모에서 사실상 미개척 영역.

- 한국 테마 덱빌딩 로그라이크는 글로벌 시장에서 완전한 블루오션
- Balatro의 "패턴 완성 → 보상" 성공 공식과 구조적으로 동형

**미채택 대안:**
- B안 부적 덧그리기 — 차별화 중간, 1인 개발 난이도 상, Zet Zillions 선례 있음
- C안 오행 상성 — 차별화 낮음, 속성 시스템 포화, 전략 깊이 부족

---

## 세계관

- **보스 후보:** 도깨비, 구미호, 귀신, 이무기, 저승사자, 염라대왕, 호랑이
- **시스템 소재:** 음양오행, 부적(유물), 도술, 무기(환도/활/창), 기
- **막 구조:** 한양 → 산속 → 무덤 → 저승 (후보)

---

## 디자인 원칙

1. 직업마다 완전히 다른 플레이 패턴 — 재플레이 동기 핵심
2. 유물/부적 등 적용된 효과를 언제든 확인 가능한 UI 구조
3. 층당 방 수를 충분히 — 런이 짧게 느껴지지 않도록
4. 첫 런에서 자연스럽게 튜토리얼 되는 구조
5. 모바일 세로 화면 기준으로 레이아웃 처음부터 설계
