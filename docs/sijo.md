# 시조전 — 시조 리듬 시스템 상세 설계

> 버전: 0.1 | 최종 업데이트: 2026-04-01
> 구현 API는 `code_structure.md` → SijoSystem 참조.

---

## 개요

카드마다 음보 수 [3] 또는 [4]가 붙어있음.
턴 안에서 초장(3→4) + 중장(3→4) + 종장(3→4) 패턴을 완성하면
시조 완성 → 마지막 카드 효과 폭발 증폭.

---

## 슬롯 구조

| 슬롯 번호 | 위치 | 필요 음보 |
|-----------|------|----------|
| 1 | 초장-1 | [3] |
| 2 | 초장-2 | [4] |
| 3 | 중장-1 | [3] |
| 4 | 중장-2 | [4] |
| 5 | 종장-1 | [3] |
| 6 | 종장-2 | [4] |

**규칙:**
- 슬롯 순서 엄수 — 해당 슬롯 음보와 다른 카드를 내면 슬롯이 채워지지 않음 (카드 효과는 정상 발동)
- 전투 종료 시 슬롯 초기화
- 턴 사이 슬롯 유지 — 턴 종료 후에도 진행 상태 유지

---

## 부분 완성 보상 체계 (ZER-101)

| 마일스톤 | 슬롯 수 | 트리거 | 보상 |
|----------|---------|--------|------|
| 초장 완성 | 2 | 초장-1[3] + 초장-2[4] 순서 완성 | 기 1 즉시 회복 |
| 중장 완성 | 4 | 초장 완성 후 중장-1[3] + 중장-2[4] 완성 | 카드 1장 드로우 |
| 시조 완성 | 6 | 전체 6슬롯 순서 완성 | 마지막 카드 효과 2배 + 기 1 회복 + 드로우 1 |

> 부분 보상은 누적. 초장 완성 후 중장 완성 시 두 보상 모두 적용.
> 단, 슬롯 순서 엄수 — 초장 미완성 시 중장 보상 없음.

---

## 와일드카드 규칙 (ZER-101)

beat 값이 0인 카드는 와일드카드. 어느 시조 슬롯([3] 또는 [4])에나 배치 가능.

**규칙:**
1. 와일드카드를 슬롯에 배치하면 해당 슬롯의 required_beat를 충족한 것으로 간주.
2. 와일드카드의 카드 효과는 시조 완성 보너스의 '마지막 카드 효과 2배'를 받을 수 있음.
3. 와일드카드는 시조 완성에 기여하지만 슬롯 점수 계산 시 해당 슬롯의 beat 값(3 또는 4)으로 인식.

**와일드카드 목록:**

| ID | 이름 | 코스트 | 효과 |
|----|------|--------|------|
| M011 | 흥 | 1 | 드로우 1, 와일드 슬롯 |
| M012 | 여백 | 0 | 방어도 2, 와일드 슬롯 |

> 와일드카드는 슬롯 유연성이 핵심 가치. 직접 효과는 의도적으로 낮게 설계. 덱당 1~2장이 최적.

---

## 핵심 자원 설계

| 자원 | 값 |
|------|-----|
| 기 기본 | 3/턴, 이월 없음 |
| 기 상한 | 없음 (기공·유물로 최대 5~6기 가능) |
| 시조 슬롯 수 | 3 (초장, 중장, 종장) — 매 턴 1 사이클 완성 (ZER-266) |
| HP 기본 | 캐릭터별 상이 (도사 75, 무관 80, 문관 70) |
| 전투 간 HP 회복 | 없음. 아이템·특수 노드에서만 회복 |
| 보스 처치 후 회복 | 최대 HP × 20% |

## 콤보 예시

### 기본 완성
초장: 기공[3] → 결인[4]  
중장: 수결[3] → 화염구[4]  
종장: 축지법[3] → **진언[4]** 💥 시조 완성 — 진언 효과 2배(AoE 8) + 기 1 + 드로우  
총 기 소모: 7기

### 태산붕 폭발
초장: 베기[3] → 결인[4]  
중장: 수결[3] → 오행지법[4]  
종장: 축지법[3] → **태산붕[4]** 💥 시조 완성 — 태산붕 40 피해 + 기 0으로 초기화

### 실패 예시
- 초장-1에 [4] 음보 카드를 내면 슬롯 불성립 → 시조 불완성
- 초장-1에 [기공 3] 후 초장-2에도 [기공 3]을 내면 음보 규칙 위반

## UI 설계 노트

- 음보 패턴을 시각적 게이지/슬롯으로 표현 → 텍스트 의존 최소화
- 카드 위에 숫자(3/4) 하나만 표시 → 작은 화면에 유리
- 종장 완성 시 화면 전체 이펙트 + 꽹과리/가야금 히트음
- 초장/중장/종장을 3개 슬롯으로 시각화 → 글로벌 유저도 직관적 이해

## 비주얼 힌트 스펙 (ZER-101)

| 규칙 ID | 트리거 | 효과 |
|---------|--------|------|
| VH1 | 카드 드래그 시작 | 다음 슬롯 녹색 펄스 하이라이트 (0.5초 주기). 불일치 슬롯은 반투명 회색 |
| VH2 | 와일드카드(beat=0) 드래그 | 비어있는 모든 슬롯 녹색 하이라이트 |
| VH3 | 잘못된 슬롯에 드롭 (beat 불일치) | 슬롯 빨간 플래시 0.2초 + 카드 원위치 애니메이션 + 에러 효과음. 모바일: 햅틱 0.05초 |
| VH4 | 슬롯 위 호버 (beat 일치) | 슬롯 황금 테두리 강조 + 미리보기 효과 |

구현: `SijoSystem.gd`에 `signal card_hovered(card_id)` 추가 필요.

## 시조 완성 연출 스펙

### 부분 완성 연출

| 마일스톤 | VFX | SFX | 햅틱 |
|----------|-----|-----|------|
| 초장 완성 | 초장 슬롯 2개 황금 파티클 0.3초 | 가야금 단음 1개 (피치 중간) | 없음 |
| 중장 완성 | 중장 슬롯 + 초장 잔광 0.3초 | 가야금 단음 2개 연속 (피치 중→고) | 햅틱 0.05초 |

### 전체 완성 연출

1. 종장 슬롯 채워짐 → 0.1초 딜레이
2. 전체 슬롯(6개) 순서대로 황금 파티클 웨이브 (각 0.05초 간격)
3. 화면 전체 황금빛 플래시 0.25초 (최대 밝기 50%)
4. 마지막 카드 2배 효과 숫자 팝업 (황금색 폰트)
5. 파티클 페이드아웃 0.5초

SFX: 꽹과리 히트 + 가야금 글리산도 (0.8초)  
햅틱: 0.15초 중간 강도 진동 (iOS: `UIImpactFeedbackGenerator.medium`, Android: `VibrationEffect.createOneShot`)  
UI 텍스트: "시조 완성!" 팝업 1초간 표시 후 페이드

구현: Godot 4 `GPUParticles2D`. SFX: `AudioStreamPlayer` (`sijo_complete.ogg`, `sijo_partial.ogg`).

## 인터랙티브 튜토리얼 스펙

**씬:** `scenes/tutorial/sijo_tutorial.tscn`  
**트리거:** 첫 런 시작 시 선택적 팝업. "튜토리얼 플레이 / 건너뛰기" 선택.

**튜토리얼 설정:**
- 적: 허수아비 (HP 10, 공격 0 — 피해 위험 없음)
- 핸드: beat 3·4 각 3장씩 미리 구성

| 단계 | 안내 텍스트 | 행동 |
|------|------------|------|
| 1 | "[3] 표시된 카드를 초장 첫 슬롯에 놓으세요." | 초장-1 슬롯 강조 |
| 2 | "[4] 표시된 카드를 초장 둘째 슬롯에 놓으세요." | 초장 완성 보상 데모: "기 +1" |
| 3 | "같은 방식으로 중장을 완성하세요." | 힌트 없이 직접 선택 |
| 4 | "종장을 완성하면 시조 완성! 마지막 카드 효과가 2배가 됩니다." | 종장 강조, ×2 뱃지 |
| 5 | "와일드카드(◇ 표시)는 어느 슬롯에든 배치할 수 있어요." | M011 '흥' 추가 후 메인 런 전환 |

건너뛰기 선택 시 즉시 메인 런 시작. 설정에서 재관람 가능.  
진행 상태: `SaveManager.tutorial_complete` 플래그로 관리.
