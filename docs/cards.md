## 카드 타입 (StS 표준)

| 타입 | 설명 |
|------|------|
| `attack` | 적에게 피해를 주는 카드 |
| `skill` | 방어/유틸리티 카드 (구 spell/movement/formation 통합) |
| `defense` | 방어도를 올리는 카드 |
| `power` | 영구 패시브 효과 부여 |
| `status` | 비자발적으로 덱에 섞이는 약한 카드 |
| `curse` | 덱에 섞이는 해로운 카드 |

## 상태이상 정의

| ID | 타입 | 효과 |
|----|------|------|
| 화상 | DoT | 매 턴 n 피해. n턴 후 소멸 |
| 약화 | 디버프 | 다음 공격 피해 25% 감소. 1회 발동 후 소멸 |
| 취약 | 디버프 | 받는 피해 25% 증가. 2턴 후 소멸 |
| 냉기 | 디버프 | 다음 턴 드로우 1장 감소. 1턴 후 해제 |
| 독 | DoT | 매 턴 n 피해, n이 1씩 감소. 0이 되면 소멸 |
