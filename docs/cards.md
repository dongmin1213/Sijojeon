## 상태이상 정의

| ID | 한자 | 타입 | 효과 |
|----|------|------|------|
| 화상 | 火傷 | DoT | 매 턴 n 피해. n턴 후 소멸 |
| 약화 | 弱化 | 디버프 | 다음 공격 피해 25% 감소. 1회 발동 후 소멸 |
| 취약 | 脆弱 | 디버프 | 받는 피해 25% 증가. 2턴 후 소멸 |
| 냉기 | — | 디버프 | 다음 턴 드로우 1장 감소. 1턴 후 해제 |
| 독 | 毒 | DoT | 매 턴 n 피해, n이 1씩 감소. 0이 되면 소멸 |
| 병사 토큰 | 兵士 | 버프 | 피해 1회 대신 받고 소멸. 소멸 시 기 1 회복 |
| 포위됨 | 包圍됨 | 디버프 | 공격 피해 25% 감소. 턴마다 지속 시간 -1 |
