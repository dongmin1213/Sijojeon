# 시조전 — 그래픽 에셋 리스트

> 버전: 0.1 | 최종 업데이트: 2026-04-06
> NanoBanana (Gemini Plus) 기반 이미지 생성 대상 목록

---

## 개요

총 필요 에셋: **약 170개** (카드 일러스트 제외 시 ~80개)
생성 도구: Google NanoBanana 2 (Gemini Plus 구독)
출력 형식: PNG, 투명 배경 권장, 해상도 1024×1024 이상
게임 해상도: 모바일 1080×1920 세로

---

## 아트 스타일 가이드

| 항목 | 설정 |
|------|------|
| 기본 스타일 | 한국 전통 수묵화 + 현대 디지털 일러스트 혼합 |
| 색상 톤 | 단청 컬러 — 주홍, 남색, 송록, 금박, 자주 |
| 배경 처리 | 카드/적 일러스트는 투명 또는 단색 배경 |
| 분위기 | 어둡고 장엄한, 약간의 미스터리 |
| 참고 작품 | Slay the Spire 카드 아트, 조선시대 민화, 단원 김홍도 풍속화 |

## 에셋 명명 규칙

```
art/cards/{card_id}.png       — 카드 일러스트 (예: art/cards/M001.png)
art/enemies/{enemy_id}.png    — 적 스프라이트 (예: art/enemies/E001.png)
art/characters/{class}.png    — 캐릭터 초상화
art/relics/{relic_id}.png     — 유물 아이콘
art/ui/icons/{icon_name}.png  — UI 아이콘
art/backgrounds/{bg_id}.png   — 배경 이미지
art/events/{event_id}.png     — 이벤트 삽화
```

TextureManager가 자동으로 위 경로에서 PNG → SVG 순서로 탐색하며, 없으면 placeholder를 생성한다.
