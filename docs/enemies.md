## Act 1: 한양

> 조선의 수도. 부패한 관리, 거리의 불량배, 억울한 귀신이 뒤섞인 도시.

### 일반 몬스터

#### E001 — 불량배(不良輩)

| 항목 | 내용 |
|------|------|
| HP | 20~28 |
| 설명 | 한양 골목의 건달. 빠르고 거칠지만 무모하다. |
| 보상 | 골드 10~20, 카드 확률 20% |

**행동 패턴** (순서 반복): 난도질(6) → 난타(3×3=9) → 도발(약화 1) → 난도질 → 난타

> 약한 초반 일반 몬스터. 난타(3×3=9)가 방어도를 뚫을 수 있어 긴장감 유지.

#### E002 — 포졸(捕卒)

| 항목 | 내용 |
|------|------|
| HP | 28~36 |
| 설명 | 부패한 포도청 관리. 방패와 곤봉을 사용한다. |
| 보상 | 골드 15~25, 카드 확률 30% |

**행동 패턴**: 곤봉 타격(7) → 방패 막기(방어 8) → 철퇴 강타(11) → 기합(힘 +1) → 곤봉 타격 → 방패 막기 → 철퇴 강타

> 방어형. 방패 막기(8방어도) 시 진언(AoE)·결인+베기 콤보 활용 유도. 장기전 금지.

---

#### E003 — 원혼(冤魂)

| 항목 | 내용 |
|------|------|
| HP | 22~30 |
| 설명 | 억울하게 죽어 한양을 떠돌고 있는 귀신. |
| 보상 | 골드 12~22, 카드 25%, 유물 5% |

**행동 패턴**: 통곡(약화 1+취약 1) → 냉기 접촉(5+냉기) → 냉기 접촉 → 빙의 시도(8+약화 2) → 통곡 → 빙의 시도

> 디버프형. 냉기+약화 누적으로 시조 리듬 방해. 빠른 처치 압박.

#### E004 — 도깨비(道鬼)

| 항목 | 내용 |
|------|------|
| HP | 30~40 |
| 설명 | 한양 외곽을 배회하는 장난기 많은 도깨비. |
| 보상 | 골드 18~28, 카드 35%, 유물 5% |

**행동 패턴**: 방망이 강타(9) → 도깨비불(4+화상 2) → 기합(힘 +2) → 도깨비 박치기(14) → 방망이 강타 → 도깨비 박치기

> 상급 일반 몬스터. 기합 후 박치기(14+힘) 위험. 힘 쌓이기 전 처치 유도.

### 보스

#### B001 — 대장 도깨비(大將道鬼)

HP: 120

**페이즈 1 (100%→50%):** 황금 방망이(12) → 부하 소환(E001) → 황금 방망이 → 광역 방망이(8 AoE) → 강화(힘 +3) → 반복

**페이즈 2 (50%→0%):**
- 트리거: HP 50% 시 힘 5 추가 + "이 방망이 맛을 똑똑히 봐라!"
- 분노 강타(16) → 연속 강타(8×3=24) → 분노 강타 → 연속 강타 → 최후의 일격(28, HP<20% 조건)

> 페이즈 2: rage_strike(21), triple_slam(39총피해). 시조 완성 활용 필수. fortify 전 처치 권장.

보상: 골드 60~80, 보스 유물 1개 (확정)

#### B002 — 저승사자(冥使)

HP: 110

**페이즈 1 (100%→40%):** 심판의 눈(약화 1+취약 1) → 낫 베기(13) → 사망 표식(3스택, 스택당 5피해) → 반격 태세(방어 12+가시 3)

**페이즈 2 (40%→0%):**
- 트리거: HP 40% 시 버프 클렌즈 + 사망 카운트다운 3 발동(3턴 내 처치 못하면 HP 50% 강제 감소) + "이미 이 세상 사람이 아니니라."
- 낫 회오리(6×4=24) → 최후의 심판(20)

> 사망 카운트다운(3턴 내 처치 강요). 시조 완성으로 폭딜이 핵심.

보상: 골드 60~80, 보스 유물 1개 (확정)

#### B_ACT1_FINAL — 판서 이무령(判書 李茂令) ← Act 1 최종 보스

> "감히 누가 판서의 앞을 막느냐. 이 인장이 곧 법이니라."

HP: 115 | 설계 주제: 부패한 권위 — 페이즈마다 다른 압박

| 페이즈 | HP 범위 | 설명 |
|--------|---------|------|
| 1 | 100%→65% | 권세 모드 — 디버프 누적, 호위 소환 |
| 2 | 65%→30% | 진노 모드 — HP 65% 시 힘 3+가시 2 획득 |
| 3 | 30%→0% | 최후 모드 — 사망 카운트다운 4 + 디버프 클렌즈 |

**페이즈 1 패턴:** 권위의 눈초리(약화+취약) → 인장 타격(10) → 관인 방패(방어 14) → 인장 타격 → 문서 지옥(냉기+약화) → 금의위 소환(E002) → 인장 타격

**페이즈 2 패턴:**
- 트리거: "감히 판서를 건드려! 목이 열 개라도 모자라겠구나!"
- 금인 강타(14, 힘 3 적용 시 17) → 권력 남용(8+약화 2+취약 1) → 이중 인장(9×2=18) → 분노 강화(힘 +2) → 반복

**페이즈 3 패턴:**
- 트리거: 디버프 클렌즈 + 힘 2 + 사망 카운트다운 4 + "왕명이니라! 이 자를 당장 처형하라!"
- 왕명 집행(8×3=24, 버프 1개 박탈) → 진노의 인장(22) → 최후의 권위(방어 10+힘 1)

보상: 골드 70~90, 보스 유물 1개 (확정)

**보스 유물 후보:**
- 부패한 인장(腐敗印章): 전투 시작 시 힘 2 획득. 첫 번째 카드 사용 시 약화 1 자신에게 부여.
- 판서의 장부(判書帳簿): 전투 시작 시 금화 10 획득. 적 처치마다 금화 5 추가.

> 총 전투 목표 14~17턴. 페이즈 3 사망 카운트다운 4턴 내 처치 강요 → 시조 완성 DPS 레이스 필수.
