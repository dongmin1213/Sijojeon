# 시조전 — 수익화 모델

> 버전: 0.1 | 최종 업데이트: 2026-04-01

---

## 기본 모델

| 항목 | 내용 |
|------|------|
| 타입 | 무료 + AdMob 광고 |
| 가챠 | 없음 — 순수 덱빌딩, 런마다 리셋 |
| 사업자 등록 | 불필요 (구글 플레이 기준) |

---

## 스토어 별 운영 방식

### 구글 플레이

- 수익 모델: 무료 + AdMob 광고
- 사업자 등록 불필요
- AdMob 연결 기준 스토어

### 원스토어

- 수익 모델: 무료 + AdMob 광고
- 구글 플레이 동시 출시 시 작동 가능
- AdMob 미작동 시 → ONE AdMax SDK로 코드 분기 대응

---

## 크로스 퍼블리싱 규칙

1. 같은 패키지명으로 양쪽 동시 출시 → AdMob 구글 플레이 기준 연결
2. 원스토어 AdMob 미작동 시 → ONE AdMax SDK로 코드 분기 대응
3. 사업자 등록 없이 운영 가능한 구조
