# 시조전 — 직업(클래스) 설계

> 버전: 2.0 | 최종 업데이트: 2026-04-15
> 순수 Slay the Spire 클론 — 조선시대 테마만 적용
> 삭제된 요소: 클래스 고유 자원, 액티브 스킬, 병사 토큰, 시조 연동 패시브

---

## 플레이어블 직업 (6종 확정)

### 1. 의적 (mugwan) — 기본 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 활빈당 의적. 칼로 부패를 베고 빼앗아 나눈다 |
| HP | 80 |
| 플레이스타일 | 공격 위주 + 광역 딜 |
| 해금 조건 | 기본 해금 — 게임 시작부터 사용 가능 |

**시작 유물 — 활빈당 두건(RS002)**

---

### 2. 선비 (mungwan) — 1막 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 디버프 지배 + 광역 폭발을 터뜨리는 학술형 관료 |
| HP | 70 |
| 플레이스타일 | 디버프 지배 + AoE 폭발 |
| 해금 조건 | 임의 캐릭터로 1막 보스 처치 |

**시작 유물 — 벼루(RS003)**

---

### 3. 의녀 (uiwon) — 5회 완주 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 약초와 독을 다루는 조선의 여의사 |
| HP | (데이터 참조) |
| 플레이스타일 | 회복 + 독 중독 + 지구전 |
| 해금 조건 | 임의 캐릭터로 런을 5회 완주 |

**시작 유물 — 약방 주머니(RS006)**

---

### 4. 무당 (dosa/mudang) — 의녀 보스 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 귀신을 부리고 굿으로 저주하는 신내림 주술사 |
| HP | 75 |
| 플레이스타일 | 에너지 관리 + 개인 폭딜 |
| 해금 조건 | 의녀로 임의 막 보스를 1회 처치 |

**시작 유물 — 신내림 방울(RS001)**

---

### 5. 기생 (gungsu) — 의적 보스 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 시/음악/무용으로 전장을 지배하는 예인 전사 |
| HP | (데이터 참조) |
| 플레이스타일 | 준비 턴 + 폭발 딜 |
| 해금 조건 | 의적으로 임의 막 보스를 1회 처치 |

**시작 유물 — 비파(RS007)**

---

### 6. 승병 (sangin) — 10회 완주 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 불심으로 싸우는 조선 임진왜란기 전투 승려 |
| HP | (데이터 참조) |
| 플레이스타일 | 방어/공격 하이브리드 |
| 해금 조건 | 임의 캐릭터로 런을 누적 10회 완주 |

**시작 유물 — 목탁(RS008)**

---

## 해금 흐름

```
의적(기본) -> 1막 클리어 -> 선비 해금
 -> 의적 보스 클리어 -> 기생 해금
 -> 5회 완주 -> 의녀 해금
 -> 의녀 보스 클리어 -> 무당 해금
 -> 10회 완주 -> 승병 해금
```

## 미래 직업 후보

| 직업 | 메카닉 |
|------|--------|
| 암행어사 | 평민으로 위장하다 마패 공개 시 "출도!" — 신분 전환으로 완전히 다른 카드군 해제 |
| 판수 | 적 정보 전혀 안 보이는 대신 덱 미리보기 능력 — 맹목과 예지의 역설 |
| 전기수 | 소설 낭독으로 적을 멈추게 함 — 이야기로 싸우는 완전히 새로운 컨셉 |
| 검계 자객 | 처치한 적의 기술을 영구 습득 — 서얼/중인 출신 지하 검객 조직 |
| 역관 | 적 카드를 복사/번역해서 역이용하는 정보 비대칭 플레이 |
