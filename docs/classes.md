# 시조전 — 직업(클래스) 설계

## 플레이어블 직업

### 도사 (道士) ★★★★☆ — 첫 번째 캐릭터

| 항목 | 내용 |
|------|------|
| 컨셉 | 전우치형 트릭스터. 기(氣)를 다루는 조선의 방술가. |
| 메카닉 | 기(氣) 조작, 도술(DoT·버프·광역), 시조 완성 보상 극대화 |
| HP | 75 |
| HP 근거 | StS Ironclad(80)보다 낮고 Silent(70)과 유사. 술법형 캐릭터는 방어보다 디버프/회피로 생존 — 낮은 HP로 긴장감 유지 |
| 플레이스타일 | 기 관리 + 시조 리듬 완성 + 개인 폭딜 |
| 키워드 | 술법(Spell), 기(氣) 관리, 원거리 공격 |

**패시브 — 천지기(天地氣):** 턴 종료 시 시조 슬롯이 2칸 이상 채워져 있으면 기(氣) 1을 회복한다.

**액티브 — 방술 개방(方術開放)** (전투당 1회): 전투 시작 시 1회 발동. 시조 슬롯 처음 2칸을 [기공 3] → [결인 4] 순서로 자동으로 채운다.

**시작 유물 — 부적 낭(符籍囊, RS001):** 전투 시작 시 손패에 무작위 부적 카드(T001~T005 중 1장) 1장 추가.

### 무관 (武官) ★★★☆☆ — 두 번째 캐릭터 후보

| 항목 | 내용 |
|------|------|
| 컨셉 | 진형(陣形) 카드로 전투 패턴 변환, 병력 토큰 지휘 |
| 메카닉 | 병사 토큰 생성 → 진형 강화 → AoE 폭딜의 3단계 반복 사이클 |
| HP | 80 |
| HP 근거 | 진형과 병사 토큰으로 실질 피해를 줄이는 구조. 높은 HP로 방어 플레이에 적합 |
| 플레이스타일 | 토큰 축적 + 광역 폭딜 |
| 키워드 | 진형(Formation), 병사 토큰, AoE 공격 |

**패시브 — 지휘통솔(指揮統率):** 병사 토큰이 1개 이상 있으면 매 턴 시작 시 방어도 2를 추가로 획득한다.

**액티브 — 군령 하달(軍令 下達)** (전투당 1회): 현재 보유한 병사 토큰 수만큼 기(氣)를 즉시 회복한다. (최대 3기)

**시작 유물 — 마패(馬牌, RS002):** 전투 시작 시 병사 토큰 1개를 자동으로 생성한다.

### 문관 (文官) ★★★☆☆ — 세 번째 캐릭터

| 항목 | 내용 |
|------|------|
| 컨셉 | 학식(學識)을 축적하여 취약 디버프 + 광역 폭발을 터뜨리는 학술형 관료 |
| 메카닉 | 학식 적립 → 소비 폭발, 취약·약화·파직 디버프 지배 |
| HP | 70 |
| HP 근거 | 학식 축적 → 폭발형 지략 캐릭터. HP가 낮지만 취약 디버프와 광역 폭딜로 전투를 빠르게 끝내는 전략 |
| 플레이스타일 | 학식 축적 + 디버프 지배 + AoE 폭발 |
| 키워드 | 학식(Scholarship), 취약(Vulnerable), 광역 공격 |

**패시브 — 학식충전(學識充電):** 턴 종료 시 이번 턴에 카드를 3장 이상 사용했으면 학식 1을 획득한다.

**액티브 — 경연개설(經筵開設)** (전투당 1회): 학식을 즉시 3 획득한다.

**시작 유물 — 필연(筆硯, RS003):** 전투 시작 시 학식 2를 획득한다.

## 미래 직업 후보

### 1순위 — 조선만의 독창적 메카닉

| 직업 | 메카닉 |
|------|--------|
| 암행어사 | 평민으로 위장하다 마패 공개 시 "출도!" — 신분 전환으로 완전히 다른 카드군 해제 |
| 무당/무녀 | 런마다 다른 신(神) 선택 → 빙의로 덱 성향 자체가 바뀌는 멀티 덱 시스템 |
| 판수 | 적 정보 전혀 안 보이는 대신 덱 미리보기 능력 — 맹목과 예지의 역설 |
| 전기수 | 소설 낭독으로 적을 멈추게 함 — 이야기로 싸우는 완전히 새로운 컨셉 |

### 2순위 — 독창적

| 직업 | 메카닉 |
|------|--------|
| 도사(전우치형) | 둔갑술·분신·축지법 — 트릭스터형, 기(氣) 자원으로 술법 발동 |
| 검계 자객 | 처치한 적의 기술을 영구 습득 — 서얼·중인 출신 지하 검객 조직 |
| 역관 | 적 카드를 복사·번역해서 역이용하는 정보 비대칭 플레이 |
| 서얼 | 불리한 상황일수록 원한(怨恨)이 쌓여 강해지는 역설 성장 |
| 기생(예기) | 시·음악·무용으로 적 매혹/혼란 — 예술을 무기화 |

### 3순위 — 활용 가능

| 직업 | 메카닉 |
|------|--------|
| 의관/의녀 | 독·해독·치료 3중 트리 |
| 음양관 | 음(陰)/양(陽) 게이지 균형 → 합체 스킬 발동 |
| 보부상 | 전투 중 상점 카드 구매, 물물교환으로 적 카드 전환 |
| 승병 | 불심(佛心) 게이지 — 방어와 공격 전환 하이브리드 |
| 포수 | 장전-발사 2단계 카드, 탄약 자원 관리 시스템 |
| 백정 | 적 처치 시 부위별 재료 획득 → 아이템 제작 |
| 광대/재인 | 흥(興) 게이지 — 무작위성 높은 공연 카드, 변장 스킬 |
| 화원 | 전투 전 맵에 함정 배치, 적 약점 스케치로 디버프 |
| 천문관 | 별자리 배열로 이번 턴 덱 순서 예측·조작 |
| 지관 | 지맥(地脈) 카드로 전투 지형 변경, 묘자리 저주 |
| 해녀 | 숨(산소) 자원 관리 — 수중에서 강하지만 지속 시간 제한 |
| 홍길동형 의적 | 분신술 카드, 적 카드/아이템 탈취 |
| 바리데기형 | HP 0에서 저승 덱 발동 — 죽음 직전 역전 메카닉 |
