# 시조전 — 직업(클래스) 설계

## 플레이어블 직업 (6종 확정)

### 1. 의적 (mugwan) — 기본 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 활빈당 의적. 칼로 부패를 베고 빼앗아 나눈다 |
| 메카닉 | 병사 토큰 생성 → 진형 강화 → AoE 폭딜의 3단계 반복 사이클 |
| HP | 80 |
| 고유 자원 | 기력 (최대 8) |
| 플레이스타일 | 토큰 축적 + 광역 폭딜 |
| 키워드 | 진형(Formation), 병사 토큰, AoE 공격 |
| 해금 조건 | 기본 해금 — 게임 시작부터 사용 가능 |

**패시브 — 지휘통솔:** 병사 토큰이 1개 이상 있으면 매 턴 시작 시 방어도 2를 추가로 획득한다.

**액티브 — 군령 하달** (전투당 1회): 현재 보유한 병사 토큰 수만큼 기를 즉시 회복한다. (최대 3기)

**시작 유물 — 활빈당 두건(RS002):** 전투 시작 시 병사 토큰 1개를 자동으로 생성한다.

---

### 2. 선비 (mungwan) — 1막 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 학식을 축적하여 취약 디버프 + 광역 폭발을 터뜨리는 학술형 관료 |
| 메카닉 | 학식 적립 → 소비 폭발, 취약·약화·파직 디버프 지배 |
| HP | 70 |
| 고유 자원 | 학식 (최대 8) |
| 플레이스타일 | 학식 축적 + 디버프 지배 + AoE 폭발 |
| 키워드 | 학식(Scholarship), 취약(Vulnerable), 광역 공격 |
| 해금 조건 | 임의 캐릭터로 1막 보스 처치 |

**패시브 — 학식충전:** 턴 종료 시 이번 턴에 카드를 3장 이상 사용했으면 학식 1을 획득한다.

**액티브 — 경연개설** (전투당 1회): 학식을 즉시 3 획득한다.

**시작 유물 — 벼루(RS003):** 전투 시작 시 학식 2를 획득한다.

---

### 3. 의녀 (uiwon) — 5회 완주 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 약초와 독을 다루는 조선의 여의사 |
| 메카닉 | 회복·독 DoT, 약재 자원 관리. 지구전형 생존 플레이 |
| HP | (데이터 참조) |
| 고유 자원 | 약재 (최대 8) |
| 플레이스타일 | 회복 + 독 중독 + 자원 관리 |
| 키워드 | 회복(Heal), 독(Poison), 약재(Herb) |
| 해금 조건 | 임의 캐릭터로 런을 5회 완주 |

**패시브 — 약초학:** 턴 종료 시 이번 턴에 회복 또는 독 카드를 사용했으면 약재 1을 획득한다.

**액티브 — 처방전** (전투당 1회): 약재를 2 소비하여 HP 8을 회복한다.

**시작 유물 — 약방 주머니(RS006):** 전투 시작 시 약재 2를 획득한다.

---

### 4. 무당 (dosa/mudang) — 의녀 보스 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 귀신을 부리고 굿으로 저주하는 신내림 주술사 |
| 메카닉 | 영력 → 저주/소환 DoT, 확률 메커니즘 카오스 플레이 |
| HP | 75 |
| 고유 자원 | 영력 (최대 8) |
| 플레이스타일 | 기 관리 + 시조 리듬 완성 + 개인 폭딜 |
| 키워드 | 술법(Spell), 기 관리, 원거리 공격 |
| 해금 조건 | 의녀로 임의 막 보스를 1회 처치 |

**패시브 — 천지기:** 턴 종료 시 시조 슬롯이 2칸 이상 채워져 있으면 기 1을 회복한다.

**액티브 — 방술 개방** (전투당 1회): 전투 시작 시 1회 발동. 시조 슬롯 처음 2칸을 [기공 3] → [결인 4] 순서로 자동으로 채운다.

**시작 유물 — 신내림 방울(RS001):** 전투 시작 시 영력 2를 획득한다.

---

### 5. 기생 (gungsu) — 의적 보스 클리어 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 시·음악·무용으로 전장을 지배하는 예인 전사 |
| 메카닉 | 흥 축적 → 폭발 딜, 타이밍 집중형 |
| HP | (데이터 참조) |
| 고유 자원 | 흥 (최대 8) |
| 플레이스타일 | 준비 턴 + 폭발 딜 |
| 키워드 | 흥(Excitement), 공연(Performance), 매혹 |
| 해금 조건 | 의적으로 임의 막 보스를 1회 처치 |

**패시브 — 흥겨운 무대:** 시조 슬롯을 채울 때마다 흥 1을 획득한다.

**액티브 — 절정** (전투당 1회): 현재 흥을 모두 소비하여 그 2배의 피해를 모든 적에게 준다.

**시작 유물 — 비파(RS007):** 전투 시작 시 흥 2를 획득한다.

### 6. 승병 (sangin) — 10회 완주 해금

| 항목 | 내용 |
|------|------|
| 컨셉 | 불심으로 싸우는 조선 임진왜란기 전투 승려 |
| 메카닉 | 인과 축적, 조건부 강력 카드, 방어/공격 하이브리드 |
| HP | (데이터 참조) |
| 고유 자원 | 인과 (최대 6) |
| 플레이스타일 | 적 처치로 인과 축적 + 조건부 폭발 |
| 키워드 | 인과(Karma), 참선(Meditation), 수행 |
| 해금 조건 | 임의 캐릭터로 런을 누적 10회 완주 |

**패시브 — 업보:** 적을 처치할 때마다 인과 1을 획득한다.

**액티브 — 참선** (전투당 1회): 인과 2를 획득하고 방어도 5를 얻는다.

**시작 유물 — 목탁(RS008):** 전투 시작 시 인과 1을 획득하고 방어도 3을 얻는다.

## 해금 흐름

```
의적(기본) → 1막 클리어 → 선비 해금
         → 의적 보스 클리어 → 기생 해금
         → 5회 완주 → 의녀 해금
                    → 의녀 보스 클리어 → 무당 해금
         → 10회 완주 → 승병 해금
```
